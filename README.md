# Falta Gente

Prototipo de la web **Falta Gente**: partidos de fútbol 5 y fútbol 7 entre gente que no se conoce, en Uruguay.

> ¿Querés jugar al fútbol y no llegás a 10? Anotate.

- `index.html` – portada con los partidos disponibles
- `partido-*.html` – página de cada partido (jugadores por equipo, perfil de cada jugador, pago)

Es un prototipo: los datos son de ejemplo y todavía no guarda nada.
